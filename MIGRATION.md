# Migration Guide

The migration guide lives in the `effect-firebase` package so it is published
to npm alongside the code:

➡️ [`packages/effect-firebase/MIGRATION.md`](./packages/effect-firebase/MIGRATION.md)

After installing, it is also available locally at
`node_modules/effect-firebase/MIGRATION.md`, next to
`node_modules/effect-firebase/AGENTS.md` (usage guide for coding agents).
